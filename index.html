My First Entry

August 15, 2026

This is a dedicated page just for a longer update. Before modern blogging software existed, this is exactly how people shared their thoughts: by writing a fresh HTML file for every post.

You can write as much as you want here without cluttering up your main homepage. You can even add images using the standard <img> tag. When you want to make a second post, you just copy this entire file, name it second-post.html, and change the text!
